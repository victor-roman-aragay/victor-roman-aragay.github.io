Privacy policy

What is accessed. The application requests the scope https://www.googleapis.com/auth/drive.file. That grants access only to files and folders the application itself creates; it cannot see, read, modify or delete any other file in the user's Drive, and it cannot see Gmail or Photos.

Where data is stored. Uploaded data is written to a private folder (b4-backups) in the account owner's own Google Drive. Data is encrypted on the home server before it is uploaded, using a key the owner holds and Google does not. Google therefore stores ciphertext it cannot interpret.

What is collected. Nothing. There is no analytics, no telemetry, no crash reporting, no advertising, and no tracking of any kind. The application does not create profiles and does not use the data for any purpose other than making the backup.

What is shared. Nothing. No data is transferred to any third party. No one other than the account owner has access to the files, and the folder is not shared.

Retention. Snapshots are kept on a rolling schedule (14 daily, 8 weekly, 6 monthly) and older ones are pruned automatically. The owner may delete the b4-backups folder at any time, which removes everything the application has ever stored.

Revoking access. Access can be revoked at any time at myaccount.google.com/permissions, or by deleting the OAuth client in the Google Cloud project. Revocation does not delete already-uploaded files; delete the folder for that.
